# Citing AdsorpQC

If AdsorpQC helps your research, please cite it. The repository's [`CITATION.cff`](https://github.com/sircalch/adsorpqc/blob/master/CITATION.cff) is the canonical record; GitHub's "Cite this repository" button uses it.

The all-versions DOI always resolves to the latest archived release: [10.5281/zenodo.22217574](https://doi.org/10.5281/zenodo.22217574). To cite the exact version you used, take the version DOI from the [Zenodo record](https://doi.org/10.5281/zenodo.22217574).

From the command line:

```bash
adsorpqc cite
```
