Computational Details (Publication Ready Methods)

Adsorption equilibrium in Mg-MOF-74 was simulated using Grand Canonical Monte Carlo (GCMC). Equilibration and statistical stationarity were validated using AdsorpQC v1.0.0 (Monreal-Hernández, 2026). The initial 1500 cycles (37.5%) were discarded as burn-in to eliminate initial state bias, yielding an effective sample size of N_eff = 2372 independent samples with a loading drift of 1.30%. Adsorption isotherms of CO2 at 298.1 K were fitted to non-linear analytical models, with the Dual-Site Langmuir model exhibiting optimal thermodynamic fidelity (R^2 = 0.9996, RMSE = 0.0482, AIC = -52.6). Binary mixture adsorption selectivity was evaluated using Ideal Adsorbed Solution Theory (IAST), yielding S = 258.56 [95% CI: 141.68 - 344.80] evaluated across 500 bootstrap iterations. Overall adsorption simulation quality achieved certification status: PASS.
